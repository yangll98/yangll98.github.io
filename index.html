01 / ABOUT

理解算子，
也理解硬件。

我是杨莉莉，一名 NPU 软件开发工程师。自 2023 年起在芯原科技从事 NPU 后端开发，关注模型算子如何在真实硬件上正确、高效地执行。

以 C 和 OpenVX 为主要开发基础，工作覆盖计算图分析、算子切分、存储优化、硬件指令适配，以及测试和软硬件联调。同时具备 MLIR 配套工具库迁移与接口封装经验。

02 / SELECTED EXPERIENCE

从问题，到落地。

工作项目的技术方向与职责概览

01
GRAPH OPTIMIZATION

Attention 子图优化

从计算依赖出发，改善中间数据的片上复用。

关注的问题

Attention 计算的中间数据与硬件存储层次紧密相关。优化需要同时考虑计算图依赖、可切分范围与数据复用。

我的工作

参与 Attention 子图识别、依赖分析与切分指令适配，配合既有切分流程，支持中间数据片上驻留并验证输出一致性。

Attention · Graph analysis · Memory reuse
02
OPERATOR ENGINEERING

算子适配与自动切分

连接算子语义与硬件约束，让模型部署更可靠。

关注的问题

模型中的归一化、激活与图像处理算子，需要在硬件尺寸及存储约束下保持计算语义。

我的工作

独立承担固定功能模块的软件开发、测试与硬件联调，完成多类算子在既有切分与 tiling 流程中的适配，覆盖 RMSNorm、LayerNorm、Softmax、Pooling 和 Resize。

OpenVX · Operator semantics · Tiling · Validation
03
MEMORY & STORAGE

权重存储与访存优化

关注数据如何组织、压缩、共享与迁移。

关注的问题

权重、偏置及量化参数的组织方式影响存储占用与数据传输，也需要与硬件数据格式保持一致。

我的工作

负责权重与偏置的数据重排、压缩、稀疏编码及共享适配；将压缩工具库迁移至 MLIR 项目并封装接口，验证迁移前后输出一致性。

Compression · Quantization · Data layout · Library integration
04
MODEL DEPLOYMENT

数据布局与模型部署

把数据转换、指令适配与端到端验证串联起来。

关注的问题

实际模型部署既包含计算密集型算子，也依赖数据布局转换、切片及相应的硬件适配。

我的工作

负责数据交换算子的切分方向分析和硬件指令生成，参与 KV Cache 布局转换算子适配，以及大模型与图像生成模型的 NPU 部署支持。

KV Cache · Permute · Strided Slice · Deployment

以上为工作经历中的实践概述，相关实现不作为个人开源项目展示。
